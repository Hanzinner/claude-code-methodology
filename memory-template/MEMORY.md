# Memory triggers

> Format: when the agent encounters topic X → read file Y.
> This is an **index of triggers**, not a memory itself. Keep entries short — under ~150 chars each. Detailed memories live in their own files.

## How to use this file

When you have something worth remembering across sessions, do not write it into this file. Write it to a new file (e.g. `feedback_email_style.md`, `project_acme.md`), then add a one-line pointer here under the right section.

Sections below are a starting taxonomy — rename, add, or remove to fit your work.

- **What we did before** / "when did we do X" → folder `episodic/`, one file per month (`YYYY-MM.md`)
