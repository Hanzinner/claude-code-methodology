# claude-code-methodology

Configuration files, hooks, and scripts for Claude Code.

## Contents

| Directory | What |
|-----------|------|
| `CLAUDE.md` | Operating core. Behavioral rules loaded into every conversation. |
| `hooks/` | Shell hooks for `PreToolUse`, `PostToolUse`, `UserPromptSubmit`, `SessionStart`. |
| `scripts/` | Utilities called from hooks or directly. |
| `memory-template/` | Initial layout for `memory/` (trigger index + four type examples). |
| `mcp/` | Setup notes for MCP servers (Tavily). |
| `addons/mobile-bot/` | Optional Telegram bridge to Claude Code. |
| `docs/` | Architecture, philosophy, memory system, hooks guide. |
| `settings.template.json` | Settings file generated by `install.sh` with hook paths filled in. |
| `install.sh` | Bootstrap script. |

## Install

```bash
git clone https://github.com/<you>/claude-code-methodology
cd claude-code-methodology
./install.sh
```

`install.sh`:
- Detects `claude` CLI.
- Asks scope (user → `~/.claude/`, project → `<dir>/.claude/`).
- Copies `hooks/`, `scripts/`, `CLAUDE.md`, `memory-template/` into the target.
- Generates `settings.json` with hook paths substituted.
- Offers to apt-install system deps (`poppler-utils`, `lynx`, `pandoc`, `ffmpeg`).
- Offers to install the `mobile-bot` addon (off by default).

Existing files are backed up to `*.bak-<timestamp>`.

## After install

- Hooks run automatically.
- Edit `~/.claude/CLAUDE.md` to change the operating core.
- Edit `~/.claude/memory/MEMORY.md` to add trigger pointers to your memory files.

## Compatibility

- Claude Code CLI on Linux and macOS.
- Bash; Windows needs WSL.
